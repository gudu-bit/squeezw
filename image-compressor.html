Open the free image compressor

How to compress an image

  1. Open the Squeeze image compressor.
  2. Select the Images tab and add a JPG, PNG or WebP file.
  3. Choose WebP, JPEG or PNG as the output format.
  4. Adjust the quality percentage. You can also enter a target file size in KB, MB or GB.
  5. Run compression and download the resulting image.

Choose the right image format

WebP

WebP is often a good choice for smaller web images. Check that the apps and platforms you use support it.

JPEG

JPEG is widely supported and is commonly used for photographs. It uses lossy compression, so very low quality settings can reduce detail.

PNG

PNG supports lossless compression and transparency. It can be useful for graphics, although files may be larger than comparable JPEG or WebP images.

What affects the compressed image size?

The output size depends on the original image dimensions, format, image content and quality setting. Lower quality or smaller dimensions can reduce file size, but may also reduce visible detail. A target size is a goal rather than a guarantee for every image.

For a smaller website image, consider using WebP where supported and keeping dimensions close to the size at which the image will be displayed.

Free image compression in your browser

Squeeze processes images on your device using browser features. No account is required for the image compressor. Your browser and device determine the maximum practical image size and processing speed. An internet connection may be needed to load the website's supporting libraries.

Frequently asked questions

Is this image compressor free?

Yes. Squeeze offers image compression without a paid account.

Which image formats can I compress?

The image tool accepts JPG/JPEG, PNG and WebP files. You can choose WebP, JPEG or PNG as the output format.

Can I compress JPG images online?

Yes. Select Images, upload your JPG file, choose the output format and quality, then run compression.

Can I set a target image size?

Yes. The tool includes an optional target size setting in KB, MB or GB. The result may vary depending on the image and selected format.

Will compression reduce image quality?

It can. Lossy formats and lower quality settings may reduce detail. Compare the result with the original before using it.

Are my images uploaded to a server?

The image compression tool uses browser-based processing on your device. Some supporting libraries load over the internet.
